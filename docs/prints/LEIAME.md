# Prints das telas

Salve aqui os prints do app rodando no Expo Go, com **exatamente** estes nomes (o README já aponta para eles):

| Arquivo | Tela | Como chegar |
|---|---|---|
| `01-inicio.png` | Início | Abrir o app; simulação em "72 h antes" |
| `02-inicio-durante.png` | Início durante a chuva | Início → "Simular a chuva" → "Durante" |
| `03-detalhe-rua.png` | Detalhe da rua | Tocar em "Rua das Acácias" |
| `04-quadras.png` | Quadras | Aba "Quadras" |
| `05-reportar.png` | Reportar | Aba "Reportar", com rua e tipo escolhidos |
| `06-meus-relatos.png` | Meus relatos | Aba "Meus relatos", com ao menos um relato |

Como tirar o print: iPhone, botão lateral + aumentar volume. Android, botão ligar + diminuir volume. Envie para o computador (AirDrop, cabo ou Google Fotos) e renomeie.
